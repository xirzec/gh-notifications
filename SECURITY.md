# Security Policy

## Supported versions

Security fixes are provided for the latest released version.

## Reporting a vulnerability

Please report vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/xirzec/gh-notifications/security/advisories/new).
Do not open a public issue for a suspected vulnerability.

Include the affected version, reproduction steps, potential impact, and any known
mitigations. Reports will be assessed and updates will be provided through the
private advisory.
